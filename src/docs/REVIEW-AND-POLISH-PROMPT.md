# Prompt — Code Review + Visual Polish (DevPath)

เข้าไปตรวจโค้ดเว็บ DevPath แล้วแก้ให้สวยและเรียบร้อยขึ้น
**ห้ามแตะเนื้อหาใน `content/`** และห้ามเปลี่ยน URL ของหน้าใด ๆ

ทำงานเป็น 3 รอบตามลำดับ และจบแต่ละรอบให้ `build` ผ่านก่อนไปรอบถัดไป

## รอบ 1 — Audit ก่อนแก้ (ยังไม่ต้องแก้อะไร)

อ่านโค้ดทั้งโปรเจกต์ แล้วรายงานเป็นตาราง `ปัญหา | ไฟล์ | ความรุนแรง (High/Med/Low) | วิธีแก้` โดยต้องตอบให้ครบทุกข้อนี้

1. หน้า PART ที่ยาวที่สุด (`part-20-debugging`, `part-07-auth-security`, `part-03-react`) แสดงผลครบถึงหัวข้อ `13. Memory Card` หรือเปล่า
2. มีปุ่ม ← PART ก่อนหน้า / PART ถัดไป → ท้ายทุกหน้าอ่านหรือยัง
3. component ไหนเป็น `"use client"` โดยไม่จำเป็น
4. 3D ในหน้าแรกโหลดแบบ dynamic import (`ssr: false`) หรือยัง และมี fallback ตอนมือถือกับตอน `prefers-reduced-motion` หรือเปล่า
5. มี element ไหนใช้ `position: fixed` แล้วทับเนื้อหาบ้าง
6. สีตัวอักษรคู่ไหนไม่ผ่าน WCAG contrast
7. มี console error / hydration warning ตอนเปิดหน้าแรกกับหน้าอ่านไหม

## รอบ 2 — แก้บั๊ก layout ที่เห็นจากหน้าจอจริง

### หน้าแรก

- **Navbar pill เยื้องไปทางขวา** ให้จัดกึ่งกลางจอด้วย `left: 50%` + `translateX(-50%)` กว้างสุด ~720px ลดช่องว่างข้างในลง และทำให้โลโก้, เมนู, `INDEX / 31` เว้นระยะเท่ากัน
- **ข้อความ copyright กับป้าย "BUILT BY CHAIPAWAT" ลอยทับหน้าจอ** (ทับแถบตัวเลขในหน้าแรก และทับเมนูล่างสุดของ sidebar ในหน้าอ่าน) ให้เอา `position: fixed` ออก แล้วย้ายทั้งสองอย่างไปไว้ใน `<footer>` ท้ายหน้า
- **Hero ไม่พอดีจอแรก** แถบ `31 PARTS · 346 KEYWORDS · 80 ...` ถูกตัดอยู่ขอบล่าง ให้ hero สูง `min-height: 100svh` ใช้ grid แบ่งซ้าย-ขวา และให้แถบตัวเลขอยู่ในจอแรกเสมอ
- **3D graph เล็ก แบน และลอยต่ำ** ขยายให้เต็มคอลัมน์ขวา จัดกึ่งกลางแนวตั้งให้ตรงกับหัวเรื่อง ปรับมุมกล้องให้เห็นความลึกมากขึ้น (อย่าให้ดูเป็นแผ่นเรียบ) เพิ่มขนาดจุดตามจำนวน keyword ของ PART นั้น และจัดกลุ่มสีตาม 6 ส่วนให้เห็นเป็นก้อนชัด ๆ
- **ป้าย "31 CONNECTED CONCEPTS" เอียงและอยู่ไกลจาก graph** ให้วางชิดมุมล่างของ graph แบบไม่เอียง
- **ระยะบรรทัดของหัวเรื่อง** ช่องว่างระหว่าง "Understand," กับ "not" กว้างเกินไป ให้ `line-height` ของ display เป็น ~0.92

### หน้าอ่าน

- **คอลัมน์เนื้อหากว้างเกินไป** ย่อหน้าภาษาไทยยาวเกือบ 1,300px อ่านยาก ให้จำกัด `max-width: 72ch` สำหรับข้อความ ส่วนตาราง, diagram และ header ของ PART ให้กว้างเต็มคอลัมน์ได้
- **Callout ติดป้ายผิด** ตอนนี้ทุก blockquote ขึ้นป้าย `MENTAL MODEL` หมด ให้แยกประเภทตามข้อความขึ้นต้น

  | ขึ้นต้นด้วย | ป้าย | สี |
  |---|---|---|
  | `ตำแหน่งในภาพใหญ่:` | `LOCATION` | เทา |
  | `ให้มองภาพนี้ว่า` | `SEE IT AS` | น้ำเงิน |
  | `🧠 ภาพจำ` | `MEMORY` | ม่วง |
  | อื่น ๆ | `NOTE` | เทาอ่อน |

- **เส้น `<hr>` สีดำหนาเกินไป** ให้เป็นเส้น 1px สี `--line`
- **Sidebar อ่านยาก** ชื่อ PART เป็นตัวพิมพ์ใหญ่ทั้งหมดแล้วตัดเป็น 3 บรรทัด ให้เปลี่ยนเป็นตัวปกติ (ไม่บังคับ uppercase) ขนาด 14px ตัดที่ 2 บรรทัดด้วย `line-clamp: 2` เลข PART เป็น mono และจัดชิดซ้ายตรงกันทุกแถว
- **ไอคอนใน sidebar ขนาดและสไตล์ไม่เท่ากัน** (บางอันเป็นโลโก้เทคโนโลยี บางอันเป็นไอคอนเส้น) ให้ใช้ชุดเดียวกันทั้งหมด เช่น Lucide ขนาด 16px stroke 1.75 สีเดียวกัน แล้วเปลี่ยนสีเป็น accent เฉพาะ PART ที่กำลังอ่าน
- **หัวข้อ `##` ดูบาง** ให้แสดงเลขหัวข้อเป็น mono สีจาง (`01`) ไว้หน้าชื่อ และทำชื่อหัวข้อให้หนา 600
- **Scrollbar ของ sidebar** ให้บางลงและสีกลืนกับพื้น

## รอบ 3 — Polish ให้ดูแพงขึ้น

- **สี accent:** `#FF5A1F` บนพื้นครีมได้ contrast แค่ ~2.8:1 ซึ่งไม่ผ่าน
  - ตัวใหญ่ (หัวเรื่อง "not memorize.") ให้ใช้ `#E4470F` (~3.6:1 ผ่านเกณฑ์ตัวใหญ่)
  - ตัวเล็ก ลิงก์ และ label ให้ใช้ `#C2410C` (~4.7:1 ผ่าน AA)
- **Header ของ PART (การ์ดดำ):** เลข `00` ที่เป็น outline จางจนแทบมองไม่เห็น ให้เพิ่ม opacity และขยับให้เต็มด้านขวา ชื่อ PART ใช้ขนาด `clamp(36px, 5vw, 72px)` และเพิ่มบรรทัดเล็ก ๆ ใต้ชื่อ: `13 sections · ~X min read · ส่วน: Foundation`
- **Micro-interaction:**
  - ลิงก์ในเนื้อหามีเส้นใต้วิ่งจากซ้ายไปขวาตอน hover
  - แถวใน sidebar มี hover แบบพื้นจาง ๆ + เลื่อนขวา 2px
  - "ในหน้านี้" ทางขวามีแถบสีวิ่งตามหัวข้อที่กำลังอ่าน
  - ปุ่ม copy บน code block ขึ้นคำว่า "Copied ✓" 1.5 วินาที
- **Reading progress:** เส้นบาง 2px สี accent ด้านบนสุดของหน้าอ่าน
- **ท้ายหน้าอ่าน:** การ์ด Prev / Next ขนาดใหญ่ 2 ใบ แสดงเลขและชื่อ PART พร้อมลูกศรที่เลื่อนออกตอน hover
- **มือถือ 375px:** sidebar กลายเป็นปุ่มเมนูลอยมุมล่างซ้าย "ในหน้านี้" กลายเป็น dropdown ด้านบน hero เรียงเป็นแนวตั้ง และ 3D เปลี่ยนเป็นภาพ SVG นิ่ง
